# Coach — מאמן אישי פרטי

אפליקציית אימונים חד-משתמשית. כל הנתונים נשמרים במכשיר שלך בלבד (IndexedDB) —
אין חשבון, אין שרת, אין אנליטיקס.

## הפעלה

```bash
npm install
npm run data:build       # מוריד ובונה את מאגרי התרגילים והתזונה (חד-פעמי)
npm run data:media:gifs  # מוריד תמונות + אנימציות לכל 1,324 התרגילים (~137MB, חד-פעמי)
npm run dev
```

> `data:media` (בלי `:gifs`) מוריד תמונות סטטיות בלבד — ~11MB. שתי הפקודות
> מדלגות על קבצים שכבר ירדו, אז אפשר להריץ שוב בלי חשש.

האפליקציה תרוץ על `http://localhost:5180`.

### שימוש מהאייפון

1. ודא שהמחשב והאייפון על **אותה רשת Wi-Fi**. כדאי שזו תהיה רשת הבית ולא רשת ציבורית — שרת הפיתוח פתוח לכל מי שברשת.
2. במחשב: `npm run dev:lan` (ולא `npm run dev`, שנגיש רק מהמחשב עצמו). בטרמינל תופיע שורת `Network` עם כתובת כמו
   `http://192.168.1.111:5180` — זו הכתובת של המחשב ברשת הביתית.
3. באייפון פתח **Safari** (לא כרום) והקלד את הכתובת הזו.
4. לחץ על כפתור השיתוף (ריבוע עם חץ למעלה) → **הוסף למסך הבית**.
5. עכשיו יש אייקון "Coach" במסך הבית שנפתח במסך מלא, בלי סרגל של דפדפן.

**חשוב:** בשיטה הזו המחשב חייב להיות דלוק ועם `npm run dev` רץ בכל פעם שאתה
פותח את האפליקציה בטלפון. הכתובת גם עשויה להשתנות אחרי אתחול של הראוטר — אז
פשוט תסתכל שוב על שורת ה‑Network בטרמינל.

**כדי שהאפליקציה תעבוד בלי המחשב:** ראה "פריסה" למטה.

> הנתונים נשמרים בדפדפן שבו השתמשת. מחשב ואייפון = שני מאגרים נפרדים.
> להעברה ביניהם: **More → Data & Backup → Download backup**, ואז שחזור בצד השני.

### נתוני דמו

`demo/demo-backup.json` הוא גיבוי של מתאמנת בדויה ("דנה (דמו)") עם כ-8 שבועות
היסטוריה: תוכנית A/B/C, אימוני כוח, ריצות, שינה, משקל, תזונה וסקירה שבועית.
כל הנתונים מומצאים. לטעינה: **More → Data & Backup → Restore**, בדפדפן נקי
(שחזור במצב "replace" מוחק את הנתונים הקיימים באותו דפדפן).

ליצירה מחדש עם תאריכים שמסתיימים אתמול:

```bash
node scripts/make-demo.mjs
```

## מה יש באפליקציה

| מסך | מה הוא עושה |
|---|---|
| **Today** | היום שלך: האימון המתוכנן, שקילה מהירה, סיכום תזונה |
| **Train** | תוכניות אימון — ימים, תרגילים, סטים/חזרות/מנוחה, סופרסטים, ייבוא/ייצוא |
| **Session** | נגן האימון: תיעוד סט-אחר-סט, טיימר מנוחה, השוואה לפעם הקודמת, החלפת תרגיל |
| **מזעור אימון** | חץ למטה בראש מסך האימון ממזער אותו. פס כתום קבוע מעל התפריט מחזיר אליו מכל מסך |
| **טיימר מנוחה** | מתחיל לבד בסימון סט. בין סטים לפי התוכנית, ובין תרגילים ארוך יותר עם שם התרגיל הבא. צליל, רטט והתראה — כל אחד ניתן לכיבוי |
| **הערות תרגיל** | פתק על תרגיל בתוך אימון. נכנס לסיכום השבועי מתחת למספרים, ולייצוא ה‑CSV |
| **How this works** | מדריך בתוך האפליקציה: מה נדרש ממך, מה קורה לבד, ומה לא מסתנכרן |
| **Athlete Profile** | מטרות, מגבלות, פציעות והעדפות — נכנס אוטומטית לכל סיכום שבועי |
| **Library** | 1,324 תרגילים עם סינון, הוראות באנגלית ודגשי ביצוע בעברית |
| **Progress** | גרף משקל, נפח אימון שבועי, היקפים, תמונות התקדמות |
| **Nutrition** | תיעוד מול יעד יומי (מינימלי בכוונה) |
| **Weekly Review** | מרכז את כל השבוע לסיכום אחד ושולח ל‑Claude למשוב |
| **Data & Backup** | ייצוא JSON מלא + CSV לאקסל, שחזור, מחיקה |

## פריסה — שהאפליקציה תעבוד בלי המחשב

מתארחת ב‑Cloudflare Pages ומוגנת בסיסמה דרך Cloudflare Access. **הנתונים שלך
לא עולים לשום מקום** — רק הקוד והמאגרים. האימונים, המשקל והתמונות ממשיכים
להישמר אך ורק בדפדפן של המכשיר.

הגנת הסיסמה חשובה גם מבחינת רישוי: המדיה היא © Gym visual, ואתר פומבי עם
177MB של התמונות שלהם הוא הפצה מחדש שההרשאה במאגר המקורי לא בהכרח מכסה.

**למה Cloudflare ולא Netlify:** ב‑Netlify הגנת סיסמה היא תכונה בתשלום (Pro),
כולל דרך `_headers` בחשבונות שנפתחו אחרי ספטמבר 2025. ב‑Cloudflare, Access עם
קוד חד-פעמי למייל הוא חינם עד 50 משתמשים.

### הגנת הסיסמה (פעם אחת, אחרי הפריסה הראשונה)

צריך לטפל בשתי כתובות בנפרד — Cloudflare מפריד ביניהן.

**א׳ — כתובות התצוגה המקדימה** (נוצרות בכל העלאה):
`Workers & Pages → coach → Settings → General → Preview access → Restrict previews`

**ב׳ — הכתובת הראשית:**
`Zero Trust → Access controls → Applications → Create new application → Self-hosted`

בשלב ה‑Domain התפריט מציג רק דומיינים שבבעלותך, ו‑pages.dev אינו כזה — לחץ
**Switch to custom input** והקלד את הכתובת המלאה. אחר כך: `Action: Allow`,
`Include: Emails` → המייל שלך, ושיטת התחברות **One-time PIN**.

מעכשיו כל כניסה שולחת קוד למייל שלך. **בדיקה:** פתח את הכתובת בחלון פרטי —
אם היא מבקשת התחברות, הנעילה עובדת. הממשק של Cloudflare משתנה מדי כמה
חודשים; אם השמות לא תואמים, חפש את המילים Access ו‑Applications.

## מחזור התכנון

התוכנית בנויה כ**בלוק** — תאריך התחלה + מספר שבועות (ברירת מחדל 4). מסך Train
מציג באיזה שבוע אתה נמצא, וכשהבלוק נגמר הוא מסמן שהגיע הזמן לתכנן מחדש.

**רוטציה (A → B → C):** תוכנית בלי ימים קבועים. מסך Today מציע תמיד את האימון
הבא בתור לפי מה שהושלם לאחרונה — כך שבוע שמפספסים לא שובר כלום. מתאים לתדירות
משתנה של 2-3 אימונים.

**ייבוא תוכנית:** `Train → Import a program file`. קובץ JSON עם התוכנית נטען
בלחיצה אחת במקום הקלדה ידנית. תוכניות מוכנות נמצאות בתיקיית `programs/`.
ייצוא: `Program settings → Export program`.

**החלפת תרגיל:** כפתור ההחלפה (⇄) קיים גם בעורך התוכנית וגם תוך כדי אימון.
הוא פותח את הבורר כשהוא מסונן לתרגילים שעובדים על אותו שריר, ומעדיף את אותו
סוג ציוד. הסטים והחזרות נשמרים, המשקל מתאפס.

## הביקורת השבועית

`More → Weekly Review` בונה סיכום של כל מה שתועד באותו שבוע — אימונים, נפח,
שיאים, משקל, תחושות והערות.

- **בלי מפתח API:** לחץ **Copy** והדבק בשיחה רגילה עם Claude.
- **עם מפתח API:** הזן אותו ב‑Settings ולחץ **Ask Claude for feedback**.
  זו הבקשה היחידה שיוצאת מהאפליקציה החוצה, ורק בלחיצה מפורשת שלך.
  המפתח נשמר במכשיר בלבד ולא נכלל בגיבוי אלא אם סימנת זאת במפורש.

מפתח מ‑[console.anthropic.com](https://console.anthropic.com/settings/keys).

## מקורות הנתונים

הכול מגיע ממאגרים אמיתיים. שום ערך קלורי או פרט תרגיל לא הומצא — היכן שאין
נתון במקור, השדה נשאר ריק לעריכה ידנית.

- **תרגילים** — [hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset).
  המבנה ברישיון MIT. **המדיה (תמונות/GIF) בזכויות © Gym visual** ומופצת שם
  ברשות בהפחתת רזולוציה. מותר לשימוש אישי; לשימוש מסחרי נדרש רישיון נפרד
  מ‑[gymvisual.com](https://gymvisual.com/).
- **תזונה** — [מאגר התזונה הלאומי הישראלי, משרד הבריאות](https://data.gov.il/dataset/nutrition-database)
  דרך data.gov.il, ברישיון פתוח. 4,624 פריטים עם שמות בעברית ובאנגלית.

הרצה חוזרת של `npm run data:build` מרעננת את שני המאגרים מהמקור.

## דגשי ביצוע בעברית

812 מתוך 1,324 התרגילים כוללים דגשי ביצוע בעברית שנכתבו ידנית (לא תרגום מכונה)
עבור דפוסי התנועה המרכזיים — סקוואט, דדליפט, לחיצות, משיכות וכו'. השאר מציגים
את ההוראות המקוריות באנגלית.

להוספה או עריכה: `scripts/build-data.mjs`, מערך `HE_CUES`. ההתאמה היא לפי
מחרוזת בשם התרגיל, מהספציפי לכללי. אחרי עריכה הרץ `npm run data:build`.

## שיתוף עם עוד אנשים

אין צורך בקוד. הוסף את המייל שלהם למדיניות ב‑Cloudflare Access
(`Zero Trust → Access controls → Applications → coach → Policies`) — וזהו.

כל דפדפן מחזיק מאגר IndexedDB נפרד, כך שכל אחד מקבל אפליקציה ריקה ופרטית
משלו: פרופיל משלו, תוכניות משלו, היסטוריה משלו. **אף אחד לא רואה את הנתונים
של אף אחד** — כולל אתה.

מה שזה **לא** נותן: תצוגת מאמן, מעקב אחרי ההתקדמות שלהם, או תוכניות משותפות.
לכל אלה צריך שרת ובסיס נתונים מרכזי, וזה סותר את דרישת הפרטיות שהאפליקציה
נבנתה סביבה.

## הערות

- **1RM משוער** מחושב בנוסחת אפלי `משקל × (1 + חזרות/30)`. זה אומדן; מעל 15
  חזרות הוא מפסיק להיות אמין ולכן לא מוצג.
- **נפח** = משקל × חזרות, על סטים שסומנו כהושלמו בלבד (בלי חימום).
- `public/data/` ו‑`public/exercise-media/` נוצרים מהסקריפטים ואינם בגיט.
